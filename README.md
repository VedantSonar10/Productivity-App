# MiniPro Dashboard
A modern, interactive productivity dashboard built with React and Framer Motion. This application helps users organize tasks, take notes, check weather updates, and find daily inspiration through motivational quotes.

## Features
- Interactive UI : Smooth animations and transitions using Framer Motion
- Dark/Light Mode : Toggle between themes for comfortable viewing
- Draggable Widgets : Customize your dashboard layout
- Responsive Design : Works seamlessly on desktop and mobile devices
- Micro-interactions : Subtle animations enhance the user experience
The dashboard combines functionality with an engaging user interface to make productivity enjoyable.
